Weather Website --- Mahib Chowdhury

This is a website made by me for displaying the weather. But the actual weather API doesn't work because I don't know Java Script yet. But the website itself is a template mean't to be used by someone who knows JavaScript which will be me in the future.
But everything else on this website works like the News and Maps pages. This website displays the weather Today, Tomorrow, and the next 7 days. 

The details about the weather are fake but all the stuff on the News and Maps sections have real information. It is just the Weather section which is mean't to be a template.

If you want to check out the stuff on my website you have to click Next 7 days, Tomorrow, or the today buttons on the main page of my website. 

To navigate around my website use the top bar which has "Weather", "News", and "Maps". And use the "Go back" button to go back after navigating around if you want to go back to the homepage.

I made this website by using HTML and CSS. Unlike my other websites from previous weeks on Terra I put in much more effort into the CSS part. I also built this website in VS code and use many websites for the News and Maps section.
